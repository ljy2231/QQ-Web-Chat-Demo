# QQ Web Chat Demo

QQ Web Chat 的高保真纯静态界面演示，单文件 `index.html`，通过 GitHub Pages 发布。

**在线地址：https://ljy2231.github.io/QQ-Web-Chat-Demo/**

**演示密码：`admin`**

- 不连接 QQ、NapCat 或任何后端，不会真实发送消息。
- 没有真实账号；示例联系人和消息都是虚构的，ID 仅作界面示例。
- 消息、设置、未读和登录状态仅保存在当前浏览器的 `localStorage`；点“重置示例”可恢复初始数据。
- 不包含真实密码、账号、聊天记录或服务器地址；背景图由浏览器直接向第三方图床 `t.alcy.cc` 请求，提示音已内嵌在页面中。
- 请勿在演示页输入真实账号、密码或敏感信息。

## 交互

- 登录、联系人切换、未读标记、退出登录
- 发送文本，引用和撤回自己的消息
- 图片/文件消息（本机占位，不上传）
- 设置面板：白名单、黑名单、管理员、背景、主题、提示音
- 移动端布局、正式站同款提示音（内嵌）、图床背景与随机换图

## 本地预览

直接用浏览器打开 `index.html`，或运行：

```sh
python3 -m http.server 8000
```

然后访问 `http://127.0.0.1:8000/`。

## 背景与隐私

登录页和聊天页默认共用同一张网页图床图片，由浏览器直接请求，不经过本项目服务器；切换页面不会重新随机请求。图床域名为 `t.alcy.cc`，会看到访问者的 IP，请勿在敏感环境使用。

## 限制

这是界面与交互演示，不是可用的聊天服务。引用、撤回、未读、设置、主题等仅影响本机模拟数据；不提供多人聊天、真实文件上传或消息投递。背景图来自第三方图床，可能不可用；加载失败时保留原背景。
