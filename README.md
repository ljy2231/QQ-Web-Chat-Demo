# QQ Web Chat Demo

QQ Web Chat 的纯静态界面演示，单文件 `index.html`，通过 GitHub Pages 发布。

- 不连接 QQ、NapCat 或任何后端，不会真实发送消息。
- 没有账号体系；示例联系人和消息都是虚构的。
- 消息、设置和昵称仅保存在当前浏览器的 `localStorage`，清理站点数据或点“重置示例”即可恢复。
- 不包含任何真实密码、账号、聊天记录或服务器地址。
- 请勿在演示页输入真实账号、密码或敏感信息。

## 本地预览

直接用浏览器打开 `index.html`，或运行：

```sh
python3 -m http.server 8000
```

然后访问 `http://127.0.0.1:8000/`。

## 限制

这是界面与交互演示，不是可用的聊天服务。引用、撤回、未读、设置、主题等仅影响本机模拟数据；不提供多人聊天、文件上传或真实消息投递。
